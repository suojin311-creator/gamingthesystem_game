Design Lab — 独立课堂版（含音乐和音效）

1. 完整解压 ZIP，双击 Start-Design-Lab.exe（Windows 10/11 x64）。
2. 主持页会自动打开。将右侧链接分享给同一网络的参与者。
3. 一个人先预览：点击 Join as a participant，在新标签页加入。
4. 想预览互相投票，请用另一个浏览器或隐私窗口再加入一人。
5. 大家到齐后，在主持页点击 Start writing，开始 90 秒写作。
6. 写作后只看到别人提交的内容。投票无倒计时，选完自动展示下一份。
7. 所有人完成后，静态排名停留 12 秒，两个问题各展示 4 秒，自动揭示 Goodhart’s Law。

右下角 Sound 可调音乐和音效；首次点击后浏览器才允许播放声音。
程序窗口保持开启；关闭程序会清空本轮匿名课堂数据。
需要老师电脑与参与者设备网络可互通；无需安装 Python、Node.js 或购买云托管。
这份包只包含 Design Lab，不含游戏。完整连接体验使用 Gaming-the-System-classroom.zip。
Windows x64 文件结构及内嵌素材已核验；未在真实 Windows 机器启动测试。
