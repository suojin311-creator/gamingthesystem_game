Gaming the System — 完整游戏 + Design Lab（带音乐和音效）

1. 解压整个 ZIP，双击 Start-Gaming-the-System.exe。
2. 主持页自动打开。点 Open the game 从开头试玩；Preview music & sounds 可快速试听。
3. 主持页的链接已包含 /game，分享给同一网络的同学。
4. 游戏 ending 中点 ENTER DESIGN LAB，会进入本次课堂的等候页。
5. 大家到齐后，主持页点 Start writing，开始 90 秒写作。
6. 投票不计时，也不会看到自己的内容。所有人完成后，静态排名展示 12 秒，
   两个问题各展示 4 秒，随后自动揭示 Goodhart’s Law。

右下角 Sound 可分别调整音乐和音效、或全部静音。首次点击后浏览器才允许声音。
关闭程序会清除本轮匿名课堂数据；课堂期间保持程序窗口开启。
不需要安装 Python、Node.js，不需要订阅托管；Windows 10/11 x64。
若系统询问网络访问，请允许课堂使用的网络。同学的设备需能访问主持电脑。

音乐为本项目原创合成配乐，无人声配音；三个 Level 动画共用同一主题，未逐镜头堆叠音效。
程序已在 Linux 同等服务上验证，并检查了 Windows x64 文件与内嵌素材；未在真实 Windows 机器启动测试。
