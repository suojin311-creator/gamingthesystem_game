DESIGN LAB — 独立本地课堂版 / STANDALONE LOCAL CLASSROOM

本包暂未接入游戏。支持 Windows 10/11 64 位。
This preview contains Design Lab only, not the three-level game.

老师 / TEACHER
1. 完整解压 ZIP，再双击 Start-Design-Lab.exe。
   Extract the entire ZIP, then double-click Start-Design-Lab.exe.
2. 浏览器自动打开主持页；启动程序窗口保持开启。
   The host page opens automatically. Keep the program window open.
3. 将主持页右侧的网址发给同学。同学用电脑浏览器打开。
   Share the participant URL shown on the right with the class.
4. 老师也参与时，点 Join as a participant，保留主持页标签。
   To participate too, use Join as a participant in a separate tab.
5. 到齐后点 Start writing。写作 90 秒，随后自动进入匿名展示。
   Start writing when everyone has arrived. Writing lasts 90 seconds.
6. 展示只看别人写的内容；没有倒计时，鲜花/炸弹二选一后自动进入下一份。
   See only other authors. Choose Agree or Disagree to advance; there is no review timer.
7. 提前完成的人等候；所有人选择完成后统一显示静态排行榜 12 秒。
   Early finishers wait; when everyone finishes, the static ranking stays for 12 seconds.
8. 两个反问各展示 4 秒，柔和切换后分层揭示 Goodhart's Law；引文没有双引号。
   Questions fade in sequence for 4 seconds each, followed by a gradual Goodhart reveal.
9. 结束时点 Close classroom；本次投稿和投票不写入文件，随程序关闭清空。
   Close the classroom when finished. Session data stays in memory and is cleared on exit.

先自己试玩 / TRY IT YOURSELF
主持页点击 Join as a participant。用其他浏览器或隐私窗口可模拟另一位参与者。
Use another browser or private window to submit a second reflection and try voting.
只有一个投稿者时会跳过展示自己的作品，直接进入排名。

网络 / NETWORK
老师与同学电脑需要连接可互通的网络。上课前用另一台电脑打开分享网址自测。
如防火墙出现访问提示，允许该程序接收课堂网络的连接。无需关闭整个防火墙。
多网卡电脑可在 Other local addresses 中选择当前课堂网络对应的地址。
Keep the teacher's computer awake and connected. Test a second computer before class.

费用与安装 / COST AND INSTALLATION
老师和学生都无需安装 Python、Node.js 或其他运行环境。
程序不连接云数据库、CDN、统计服务或付费接口，不需要账号或订阅。
No Python/Node.js installation, cloud subscription or third-party runtime service is required.

验证范围 / VALIDATION
21 个独立 Chromium 浏览器已用同源码 Linux 服务验证，Windows x64 程序另做格式和嵌入资源校验。
尚未在 Windows 实机运行；请在老师电脑上先试启动，再检查学校网络连通性。
This is an unsigned development preview. Native Windows startup still needs a real-device check.
