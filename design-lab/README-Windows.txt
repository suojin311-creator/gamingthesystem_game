Gaming the System — 完整游戏 + Padlet Design Lab

1. 完整解压 ZIP，运行 Start-Gaming-the-System.exe（Windows x64）。
2. 浏览器自动打开完整游戏。程序窗口显示可分享给同网络玩家的 /game 链接。
3. 游戏 ending 点击 ENTER DESIGN LAB，在游戏内全屏进入 Padlet。
4. 右上角可在新标签页打开 Padlet。所有设备需联网；访问、发布、评论和点赞权限由看板设置决定。

不再使用原来本地 Design Lab 的写作、投票、排名或主持控制台。
也可直接下载 Full-game-play.zip，打开 HTML 玩游戏并进入 Padlet，无需启动本程序。
程序只在通过老师电脑提供游戏网页时需保持开启；Padlet 内容由第三方平台提供。
旧独立 Design-Lab-local.zip 作为历史本地版本保留。
Windows 文件与内嵌素材已核验；未在真实 Windows 机器启动测试。
