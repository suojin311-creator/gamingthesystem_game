Design Lab.

用于课堂一次性开展匿名写作、鲜花／炸弹投票、排名与结尾反思。本包暂未与三关游戏合并。

在老师的 Windows 电脑上

  1. 先完整解压 ZIP，再双击 Start-Design-Lab.exe。
  2. 主持页会自动在浏览器中打开。启动程序窗口保持开启。
  3. 把主持页右侧显示的网址发给同学。同学连接可互通的网络，用浏览器打开即可。
  4. 老师自己也玩时，点 Join as a participant，保留主持页标签。
  5. 大家到齐后点 Start writing。写作 90 秒，随后自动展示。
  6. 静态排名停留 12 秒后，两个反问各展示 4 秒，平滑过渡到分层揭示的 Goodhart’s Law。
  7. 结束时点 Close classroom，本次数据随程序关闭而清空。

支持 Windows 10/11 64 位。老师和学生都无需安装 Python、Node.js 或其他运行环境；无需云服务器或付费账号。

先自己试玩

主持页点 Join as a participant 就能开始。请用其他浏览器或隐私窗口提交另一份作品以体验投票；只有一个投稿者时会直接进入排名。

关于网络

首次运行若出现防火墙访问提示，请允许这个程序在课堂网络接收连接。上课前请用另一台电脑打开分享网址，确认能看到等候页且主持页人数增加。校园网络若隔离设备，该方式需要换用可互通的网络。

主机存在多张网卡时，主持页可展开 Other local addresses 查看其他地址。活动期间保持老师电脑运行、联网且不休眠。

这一版的规则

只展示其他作者的作品。鲜花表示同意，炸弹表示不同意；没有倒计时，选择后自动进入下一份。提前完成的人等候全员完成。排名静态停留 12 秒，可手动滚动查看。展示结束后统一排名，依次出现两个反问和 Goodhart 插画与已确认的简短引文。

Windows 可执行文件由同一份 Go 服务源码交叉编译。多人流程在 Linux 服务＋Chromium 下验证；Windows 实机启动与教室网络仍需现场测试。此为开发预览，程序尚未做商业代码签名。
