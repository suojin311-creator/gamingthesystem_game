# Level 3: less reading, a clearer stopping rule

Before this revision, the full baseline was saved to GitHub branch
[`archive/pre-level3-focus-v8`](https://github.com/suojin311-creator/gamingthesystem_game/tree/archive/pre-level3-focus-v8),
commit `24d80282b83afd65ba4600f5d2fa4c2718a3f8d4`. Its original five preview ZIPs
were checked against the manifest hashes and ZIP CRCs. Keep this branch frozen.

## Narrative placement

| Moment | Presentation |
| --- | --- |
| Chapter opening | Short introduction and explicit entry button |
| Choosing / editing | Cards and sliders; no workbench conversation |
| Publication | Three published weights and explicit Observe button |
| Observation result | One teacher question and two short Alex replies |
| Comparison | All actual records aligned; direct response-cinematic button |
| Final response | Three lines, followed by the theory placeholder |

Each trial now has one review exchange instead of three operation/review
exchanges. Questions and replies still depend on the actual pattern and earlier
attempts. The second attempt stays free; no dialogue requires a more even split.

## Near-even is an improvement in distribution, not a victory condition

Near-even retains the existing inclusive ten-point spread rule and three medium
effort categories. The illustration first reveals all three task efforts, then
shows checking the rubric, collecting ticks and packing up. Only after the
visible sequence finishes can the short review begin. Hidden/off-screen
presentation waits; reduced motion removes movements without skipping evidence.

Alex stops because the criteria are satisfied. The student card names this
behaviour. No numerical learning loss or guaranteed absence of learning is
asserted. The management satisfaction progression is unchanged.

The six metric vignettes now have different props and actions: reading,
contributing, working on-screen, discussing, reflecting and responding to peers.
Near-even placeholder actions use the same tasks and explicitly show completion
followed by stopping. The finished partner animations remain separate.

## Compare changes directly

The same metric appears once per row, with first test, second test and any system
reference in adjacent columns. Values come from the immutable actual runs. All
headers have the same neutral background; markers identify changed effort,
independently of whether the split is near-even. Narrow screens keep the same
columns and place each shared metric label above its row of trial cells.

Scene/result contracts, player-name handoff, inherited Level 2 trio, confirmation
logic and the final theory-placeholder endpoint are preserved. Validation is in
`LEVEL3_VALIDATION-v9.json`; the current ZIP manifest records the rebuilt source
and all five artifact hashes.
