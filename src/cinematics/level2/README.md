# Integrated Level 2 placeholder films

`LevelTwoCinematic` is the default renderer in the existing LevelTwo scene slot.
Custom `renderCinematic` hosts still replace that entire slot.

The isolated HTML iframe uses the read-only partner delivery pinned at
`Mg614/gaming-the-system@c8c1c83456c4e67cf627df399bfb67b3a9792adb`.
`scripts/level2-animation/` trims and styles its actual acting; it does not add
gameplay rules. Prepare through `scripts/level2-film.mjs`, using
LEVEL2_ANIMATION_SOURCE on the first build. Verified cache is retained under
ignored node_modules/.cache/level2-cinematic and embedded in offline game HTML.

Only three/six/final scene requests are supported. Three begins on Alex's first
completed-requirements line. Extra growth and priority pages are never played.
Dialogue, Alex/You labels and authored checklist item/group text remain;
checklist text is an explicit exception to overlay removal. Palette, reading time, fixed camera
and opaque covers follow the approved Level 1 presentation.

Source-window/run-token checks accept the real film's final covered completion
once. The existing game instance remains mounted; its name, selection, sound
preference and next-level handoff remain in game memory. The film is silent
because the partner delivery contains no audio sources.

See docs/LEVEL2_ANIMATION_PREVIEW.md and the current PREVIEW_VALIDATION.json.
