# Play Level 1

1. Sign in to GitHub with an account that can access this repository.
2. [Download Level1-play-v3.zip](Level1-play-v3.zip?raw=true).
3. Extract the ZIP into a folder.
4. Open `Level1.html` using Google Chrome or Microsoft Edge.

No Node.js, package installation, terminal commands, or development tools are required.

This is the standalone Level 1 prototype. Cinematics and the next level remain explicitly marked placeholders. Use Restart before another player/group begins on the same browser.

Version 3 adds a four-step first-visit guide, a correctly aligned target label, louder feedback cues, and automatic animated result recaps. Use Guide to replay the introduction and Pause / Resume to control the presentation. Sound on / Sound off remains at the top right. A click or key press enables browser audio.
