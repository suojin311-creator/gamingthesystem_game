# Play Level 1

1. Sign in to GitHub with an account that can access this repository.
2. [Download Level1-play-v5.zip](Level1-play-v5.zip?raw=true).
3. Extract the ZIP into a folder.
4. Open `Level1.html` using Google Chrome or Microsoft Edge.

No Node.js, package installation, terminal commands, or development tools are required.

This is the standalone Level 1 prototype. Cinematics and the next level remain explicitly marked placeholders. Use Restart before another player/group begins on the same browser.

Version 5 shows only one classroom observation paragraph, with a quiet simultaneous student summary and one sound cue. It gives you 6–8 seconds to read before Maya and Alex reply in the main content column. Replies arrive one at a time with typing dots and 3–5 seconds of reading time each. The next-step button appears afterward. Information stays available for rereading.

Management’s view, automatic playback and fresh-page restarts remain. The guide appears for every new run and can also be reopened with Guide. Sound on / Sound off affects the current run only.

Closing the page ends that game. Reopening it starts again; no saved progress is restored.
