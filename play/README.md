# Play Level 1

1. Sign in to GitHub with an account that can access this repository.
2. [Download Level1-play-v4.zip](Level1-play-v4.zip?raw=true).
3. Extract the ZIP into a folder.
4. Open `Level1.html` using Google Chrome or Microsoft Edge.

No Node.js, package installation, terminal commands, or development tools are required.

This is the standalone Level 1 prototype. Cinematics and the next level remain explicitly marked placeholders. Use Restart before another player/group begins on the same browser.

Version 4 uses Management’s view, removes pause controls, and starts a new game every time the page is opened or refreshed. The guide appears for every new run and can also be reopened with Guide. Results and conversations still unfold automatically, with animated emphasis and sound cues. Sound on / Sound off affects the current run only.

Closing the page ends that game. Reopening it starts again; no saved progress is restored.
