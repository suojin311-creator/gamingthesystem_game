# 三份最新预览包

| 顺序 | 文件 | 解压后启动 | 用途 |
| --- | --- | --- | --- |
| 1 | [Full-game-play.zip](Full-game-play.zip?raw=true) | `Gaming-the-System.html` | 开头、Level 1–3、ending、音乐与音效；独立试玩，不含课堂服务 |
| 2 | [Design-Lab-local.zip](Design-Lab-local.zip?raw=true) | `Start-Design-Lab.exe` | 独立 Design Lab，直接分享 Lab 参与链接 |
| 3 | [Gaming-the-System-classroom.zip](Gaming-the-System-classroom.zip?raw=true) | `Start-Gaming-the-System.exe` | 同一个本地服务提供完整游戏和 Design Lab，ending 按钮直接进入本次课堂 |

第 1 和第 3 份包含局域网 HTTP 修复，以及已确认的三关自动进入和老师称呼调整。
三关入场动画结束后停留 2 秒，自动进入操作界面，不再需要点击进入按钮。
独立开头副标题与 ending 新文案仍在审阅，不包含在这次正式更新中。
更新时先关闭旧启动程序，再完整解压新版并运行，从新主持页重新复制玩家链接。
第 2 份使用同一套最新 Lab 流程、文案和音效，另外构建主持页入口；不包含游戏素材。

两个启动程序适用于 Windows 10/11 x64。参与者使用浏览器，不需安装程序。
主持电脑保持运行；其他设备需能通过课堂网络访问它，无需云托管、免费试用或订阅。
浏览器首次交互后允许声音，右下角 Sound 可以分别调整音乐和音效。

合并版使用方式：主持人启动程序 → 分享主持页的游戏链接 → 玩家完成游戏 →
ending 点击 ENTER DESIGN LAB → 在同一课堂等候 → 主持人等大家到齐后点 Start writing。
独立游戏 HTML 不提供多人课堂服务；需要连贯体验时使用第 3 份。

独立 Lab 一个人可检查写作和收尾；预览互相投票请用两个独立浏览器或隐私窗口分别提交。
只有一位投稿者时，没有其他人的作品可展示。

Windows 文件格式、架构与内嵌素材已核验；服务和浏览器验证在 Linux 进行，未在 Windows 实机启动测试。
